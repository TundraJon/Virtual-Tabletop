USER GUIDE

INITIAL SETUP

1. Load Folders: Go to Assets. Click "Load Folder". Choose your image directory for Maps & Tokens.

2. Set Map: Select your map from the dropdown list.

3. Calibrate Grid: Go to Map tab. Click "Set TL". Tap corner of top-left square. Click button again to lock. Repeat for "Set BR". Enter "Squares Across" and click "Apply Grid".

GAMEPLAY

  • Add Token: Long-press (0.6s) on the map.
  • Move Token: Drag token. Distance is shown at start position.
  • Edit HP: Long-tap a token to adjust health or delete.
  • Delete Token: Long-tap token and click "Delete". (Tokens stay at 0 HP until manually removed).

DICE ROLLER

B = extra tens die, keep lowest. P = extra tens die, keep highest. T = number of tens dice, like d100t3kl.
